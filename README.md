# BX Framework Player

Runtime and mod loader for **Hollow Knight: Silksong**, powered by BX Framework.

> BX Framework is an unofficial community project and is not affiliated with or endorsed by Team Cherry.

## About

BX Framework Player is the runtime component of BX Framework.

It provides the environment required to load and run compatible BX Framework mods for Hollow Knight: Silksong.

## Version

Current version: **v0.1.0**

## Installation

1. Download the latest `BXFramework-Player` release.
2. Extract the contents of the ZIP archive.
3. Copy all extracted files and folders into the **Hollow Knight: Silksong game directory**.
4. Start the game normally.

The files should be placed directly in the game directory, not inside an additional `BXFramework-Player` folder.

## Package Structure

A standard BX Framework Player package contains:

- `BXFramework/` — BX Framework runtime files
- `.doorstop_version` — Doorstop version information
- `doorstop_config.ini` — Runtime configuration
- `winhttp.dll` — Runtime loader

## For Mod Users

BX Framework Player is intended for players who want to run mods built for BX Framework.

Mods designed for BX Framework may require a specific Player version. Check the individual mod documentation before installation.

## For Mod Developers

Developers who want to create BX Framework compatible mods should use **BX Framework SDK**.

## Updating

When updating BX Framework Player:

1. Download the newer release.
2. Extract it into the Hollow Knight: Silksong game directory.
3. Replace or merge existing BX Framework files when required.

Always check the release notes for version-specific instructions.

## Uninstallation

Remove the BX Framework Player files that were installed into the game directory.

Back up modified files and configuration files before removing or replacing them if you want to preserve your settings.
